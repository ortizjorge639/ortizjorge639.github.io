# Hosted direct-model frog — deployment and rollback

Status: implemented, disabled by default; **not deployed**. The original loopback Copilot bridge remains separate. Never tunnel it or copy a personal CLI cache into a public host. Hosted Copilot entitlement is not assumed. The direct route needs no Copilot executable, tool permission, private corpus, browsing, or agent service.

## Reproducible local checks

Use Node22.12+, `npm ci`, `npm run build`, `npm run test:guide`, `npm run test:stories`, `npm run test:unit`, `npm test -- --workers=1`, and `npm run test:responsive -- --workers=1`. VM operators must put every heavy command inside `hermes-heavy --`; release requires the inherited macOS native-touch CI, not a Linux synthetic substitute. Ordinary CI never calls a paid provider.

`npm run dev:guide` is the original local rehearsal, loopback-only. `node --experimental-strip-types scripts/hosted-server.mjs` is a distinct hosted listener and reads `frog.yaml` (disabled) or an explicit server-side `GUIDE_CONFIG` path. It binds `PORT` (default8080). Never start an enabled hosted config on the maintainer workshop or tunnel it.

## Explicit server configuration

The parser accepts a deliberately restricted YAML scalar subset. Unknown/duplicate keys, aliases/tags, malformed values, missing limits, unsupported hosted backends, expired or >seven-day activations fail. A disabled `frog.enabled` performs no inference. Public direct selections are exactly `backend: model-api`, `access: public`, `model_provider: azure-openai`, `deployment: gpt-5-mini`. Model root must be an Azure OpenAI HTTPS origin, site origin must be the exact portfolio origin, and ledger endpoint must name `/dbs/<db>/colls/<container>/docs/global` on Cosmos HTTPS. `expires` is an explicit UTC ISO timestamp. Limits required: `lifetime_requests`<=100, `daily_requests`<=20, `lifetime_tokens`<=2,000,000, `lifetime_microusd`<=2,000,000. These are maximums, not automatic replenishment.

Credentials never belong in YAML or Vite. Production uses the dedicated host's `IDENTITY_ENDPOINT`/`IDENTITY_HEADER` platform identity only; no fallback to Azure CLI/user token caches or API keys. Grant Cognitive Services OpenAI User at the exact existing model account, and a custom Cosmos data role limited to readMetadata/items read/replace at the one container. No item create/delete, DB/container creation or metadata writes for the service identity. The separate operator initializer is a privileged one-time action, not startup behavior.

## Durable admission / billing bounds

The fixed document must already exist and match the exact parsed configuration digest. Preserve all prior real-provider reservations when initializing authoritative state; never refill on deploy/restart/config change or restore a stale ledger to an enabled app. Lifetime counters are monotonic. Cosmos conditional replace commits maximum input/output reservation before dispatch.412/429/unknown commit/missing/corrupt state => no inference; no retries or cross-provider fallback. Failed or uncertain requests are not refunded. UTF8 prompt<=48,000bytes plus256 framing tokens, generated+reasoning<=2,048tokens, one call, no tools, `store:false`, n1, no streaming,30second local deadline. Reservation uses conservative USD1/1M input and5/1M output rather than cache discounts. Verify pinned deployment version/upgrade policy and current retail rates before activation.

Concurrency is a durable semaphore, NOT an automatically expiring lease. After a validated complete provider response, a matching reservation sequence may clear it by CAS. Timeout, disconnect, invalid result, crash or ambiguous completion write leaves the global slot closed across restarts. An operator must disable the service, establish that no provider work remains, and conservatively reconcile before clearing that slot; time passage alone is not proof provider cancellation stopped billing. Never clear lifetime usage. This trades optional-chat availability for safe global concurrency.

Admission attempts are durable and bounded (30/minute,500/day,10,000 lifetime), separately from model requests; malformed/slow bodies consume attempts but no inference slot. Four process-local body readers,16connections,16KB bodies and2second body deadlines bound memory. Exact CORS origin is not authentication; origin-less clients still consume global limits. No fairness/unlimited-free guarantee is made. `GUIDE_KILL_SWITCH=1`, expired config or document disabled=true stops new inference. Already-dispatched work may continue provider-side.

## Cost/hosting admission

Use only an independently admitted fixed-cost/free configuration: the tested candidate is App Service F1 (one Linux instance, hard CPU/bandwidth quotas) plus single-region Cosmos lifetime free tier/manual400RU/s/account total cap400/one fixed-size document, no autoscale/analytical storage/paid diagnostics/private endpoints/paid backup. Keep two periodic backups only. Cosmos request throttling is not pay-per-transaction in this provisioned design. Free-tier grant, current throughput, region count and bounded document storage must be read back; do not silently provision paid alternatives. F1 is best-effort with no SLA and is not a production-supported hosting tier.

Actual host creation was refused by the authenticated subscription's F1 quota in two regions (limit0, required1), despite the read-only regional catalog advertising capacity. No host exists; no paid fallback was made. A dedicated free Cosmos account/container was provisioned and actual read/ETag conditional race/stale-write/budget persistence/disabled state were exercised with temporary operator auth. That auth assignment was removed and read back absent. This is not a deployed managed-identity API proof. One tiny actual Azure model answer also succeeded separately; no personal Copilot service proxy was used. Full private operation evidence contains exact resource handles and receipts, not public secrets.

## Frontend, privacy, release

Only after all original gates, configure `VITE_GUIDE_API=https://<approved-host>.azurewebsites.net` at build time. It accepts an exact HTTPS Azure app origin without credentials/path/query; blank stays public-disabled. Both reading and sketchbook share the guide. The public connection must return mode model-api/provider azure-openai; no local-CLI fallback on public failure. Source links are catalog-bound; textContent rendering remains mandatory. Health does not invoke inference and reports configuration separately from real authentication proof.

Questions, bounded history and public excerpts go to Azure OpenAI. Site code stores no transcripts; browser memory resets on reload/page transitions. `store:false` is not a zero-retention promise: flagged prompts/completions can be processed for abuse monitoring and human review, and Global Standard can process outside the resource region. Do not send sensitive information. See https://learn.microsoft.com/en-us/azure/foundry/responsible-ai/openai/data-privacy . Citation membership validation does not prove factual entailment; partial-grounding flags are shown.

No release until full source/history/dist/corpus privacy, visual/performance/accessibility, independent final objective/security review, real hosted identity/quota/provider/browser proof and required native macOS CI pass. Do not treat HTTP200, mocks or a local model response as public deployment proof.

Rollback: first disable hosted inference (`GUIDE_KILL_SWITCH=1` plus durable disabled flag), verify status and a negative chat attempt without new provider dispatch. Revert Pages to the last-good verified main revision, rebuild and verify exact served bytes/routes. Remove only new operation-owned infrastructure after preserving monotonic spend/evidence; never delete the shared existing model account, unrelated vault, or workshop. Verify deletion and unchanged shared resources. Turning a flag off is not infrastructure teardown. The pre-workshop last-good source SHA is14dfd0ae03bfa62c5018548e4386bd1c23d99388. No rollback was needed because no candidate was pushed, merged or deployed.
